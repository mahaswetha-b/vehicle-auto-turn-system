# Vehicle Auto Turn System

## Project Overview
This project is designed to improve vehicle safety by automatically controlling turn indications and monitoring driver conditions.

## Components Used
- Arduino Uno
- MPU6050 Sensor
- Buzzer
- LEDs
- Electronic Drive Circuit

## Features
- Drowsiness Detection
- Automatic Turn Indication
- Driver Safety Alert System
